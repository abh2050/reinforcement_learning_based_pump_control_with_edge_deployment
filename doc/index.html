01 / SYSTEM DESIGN

One control loop.
Four useful disciplines.

The work spans the whole path from plant behavior to an interface that can serve a controller—not just an isolated model notebook.

01 — MODEL

Give the plant a backbone

First-principles fluid dynamics provide a structured baseline for pump and valve behavior.

physics → response
02 — PREDICT

Learn from observations

A gradient-boosted model estimates system response from pump operating data.

data → prediction
03 — CONTROL

Optimize the next move

A PPO policy chooses actions against a multi-objective reward for flow, pressure, and stability.

state → action
04 — DEPLOY

Expose it at the edge

FastAPI endpoints and MQTT messaging connect the control logic to an operations interface.

API · MQTT · Docker
02 / EVALUATION

Show the signal.
Keep the context.

The project reports flow prediction at R² = 0.9655; pressure prediction is a clear gap at R² = 0.1188. PPO control results show better pressure tracking than flow tracking. See the project summary and training notes for methodology and detail.
