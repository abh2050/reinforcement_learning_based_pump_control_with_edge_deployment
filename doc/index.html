How it works

Four building blocks, one feedback loop.

The project combines system modeling, learning from data, policy optimization, and edge deployment into a single control stack.

01

Model the plant

A simplified fluid-dynamics model estimates how pump speed and valve setting influence flow and pressure.

speed + valve → response
02

Learn from data

Gradient-boosted models are trained on historical pump data to estimate system behavior.

data → predictions
03

Choose an action

A PPO agent learns control actions that balance target flow, pressure, energy, and stability.

state → actuator command
04

Connect at the edge

FastAPI routes and MQTT messaging provide status, prediction, and control interfaces.

API · MQTT · monitoring
Inside the controller

Why combine physics and learning?

A first-principles model gives structure and interpretability; a learned model fills in gaps that a simplified dynamics model may miss. The hybrid system blends both.

What the agent balances

  • Flow toward a target value
  • Pressure toward a target value
  • Efficient use of pump power
  • Stability to avoid oscillatory behavior

Interfaces & tools

Prototype system with an edge-ready model.

The project includes a Python control stack and operations tooling, making it easier to test and monitor a closed-loop system.

Example API methods

  • GET /status and GET /health
  • POST /predict for model response estimates
  • GET /optimize for an RL-based suggestion
  • POST /control for a live command

Important context

A prototype, not a certified control system.

Before any real-world deployment, validate against actual sensor data, add independent safety interlocks, and review the system with engineering controls and operating procedures appropriate for your environment.
